一、优化背景与范围

一期开发中，为便于开发与测试，安装类型里的 APK 与 PWA+APK（pwa优先+apk推荐） 相关配置在两个菜单的后台均做了「置灰 / 隐藏」处理，前台对应的 APK 安装分支实际未生效——需求内容本就存在，只是暂时关闭入口。

本期范围：在「推广渠道管理」与「安装引导」两菜单放开 APK / PWA+APK 安装类型及其下属字段（APK 包地址 / APK 包名 / 选择 APK）的可用性；打通前台安卓 APK / PWA+APK 安装流程；并新增「已安装唤起 + 兜底」前台逻辑。

三、修改点详述

3.1 安装类型选项去置灰 解禁

两菜单的安装类型下拉，去除 APK 选项置灰，pwa(快速安装) / apk(需要自己封装) / pwa(优先)+apk(推荐使用) 三项全部可选。选项含义与联动沿用一期，详见《推广渠道管理模块 PRD》3.5.3「弹框安装类型」及《安装引导模块 PRD》2.3「安卓安装类型」。默认值两菜单统一为 pwa(快速安装)。

3.2 APK 子字段解禁 解禁

安装类型选中含 APK 的类型时，「APK 包地址 / APK 包名 / 选择 APK」解禁可用，联动逻辑沿用一期（选马甲包自动填地址+包名，手动改地址后包名自动清空）。详见《推广渠道管理模块 PRD》3.5.3 与《安装引导模块 PRD》2.3 对应字段行。

马甲包管理菜单暂未上线：「选择 APK-选择马甲包」弹窗内下拉选项暂时留空，待马甲包管理上线后再读取列表；当前通过「上传」手动上传 apk 文件（限 100MB）跑通配置流程。

3.3 批量替换弹窗 解禁

仅「推广渠道管理」菜单涉及。参照《推广渠道管理模块 PRD》3.5.1：「更换安装包」的渠道安装类型放开 APK / PWA+APK 及其 APK 子字段；「更换安装引导」的弹框安装类型（安卓）放开 PWA / APK / PWA+APK 及其 APK 子字段。「替换渠道」仅展示安装类型完全匹配的渠道，逻辑不变。

3.4 数据表格展示 解禁

仅「推广渠道管理」菜单涉及。参照《推广渠道管理模块 PRD》3.4：删除「APK 相关配置项置灰不可操作」备注，「安装类型」列正常展示 apk / pwa+apk，「安装方式」列正常展示 APK 包地址（展示样式沿用一期）。

3.5 前台安卓安装流程与落地下载页 解禁

安装流程：参照《安装引导模块 PRD》3.4「引导安装流程（安卓分支）」，纯 APK / PWA+APK 的前台流程（含下载进度条、PWA 提示后取消降级 APK、复制链接弹框等）一期已定义，二期随 APK 上线后实际生效并联调验证，流程本身不改。

落地下载页：参照《推广渠道管理模块 PRD》3.5.3 落地页说明，仿谷歌页 / 防封下载页安卓侧「弹框安装类型 + APK 包地址生效，决定安装方式」；下载页遮罩与层级规则以《仿应用商店模块 PRD》第四章为准。

四、新增逻辑：已安装唤起 + 兜底 新增

需求目标（产品视角）：当用户设备已安装该渠道对应的 PWA 或 APK 时，在 H5 再次点击安装应直接打开已安装的应用，而非重复下载，并让用户无缝保持登录状态进入应用。本逻辑同时适用于两菜单的前台安装入口。

触发场景

用户在 H5 端点击任意安装入口：顶部固定横幅、底部安装浮层、引导安装弹窗，以及仿谷歌页 / 防封下载页的下载按钮（参照《安装引导模块 PRD》3.2 / 3.3 / 3.4）。

核心逻辑

点击安装时，系统先尝试唤起该渠道对应的、已安装在设备上的应用：

· 唤起成功（已安装）：直接打开该应用，不再重复下载。H5 页进入后用户保持与 H5 一致的登录状态，无需重新登录，无缝进入 App；下载页（仿谷歌 / 防封下载页）仅做唤起打开已装应用，不涉及登录态（下载页本身无登录）。

· 唤起失败（未安装）：兜底回落到原有安装流程，按安装类型正常触发 PWA 安装提示或 APK 下载。

· 组合类型 PWA+APK：按原有优先级（优先 PWA，不支持再 APK）判断后，唤起对应的已安装应用。

下载页点击安装流程：点击 CTA → 加载状态 → 就绪状态 → 点击「安装」→ 尝试唤起已装应用（成功则直接打开，失败再进入原下载安装流程）；详见《仿应用商店模块 PRD》4.2 / 4.3。
与原口径的关系（务必写清，避免开发理解偏差）：本逻辑不改变弹窗弹出频率——系统仍不做持续性已安装判定，顶部横幅、底部浮层、引导弹窗仍按原弹框时间点与间隔照常展示（与《安装引导模块 PRD》2.3、3.4 及《推广渠道管理模块 PRD》3.5.3 一致）。即：不是「检测到已安装就不弹了」，而是「照常弹，用户点击后先尝试打开、打不开再走安装流程」。

五、依赖与需同步确认

两菜单口径同步：「推广渠道管理」与「安装引导」的引导安装 / 安装类型为同一套逻辑，本期修改需在两菜单保持一致。安卓安装类型默认值统一为 pwa(快速安装)。

马甲包管理（系统管理）：「选择 APK-选择马甲包」依赖该菜单。当前未上线，本期以「下拉留空 + 手动上传 apk」跑通；待其上线后回补自动读取列表的联动。

《仿应用商店模块 PRD》：落地下载页的 APK 安装交互、下载中状态、下载确认弹框、PWA / APK / 复制链接弹框的遮罩与层级规则，统一以《仿应用商店模块 PRD》第四章为准。
